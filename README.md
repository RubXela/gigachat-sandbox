# 🤖 Голосовой помощник на базе GigaChat

# 🚀 Быстрый старт (веб-бот)
## 1. Клонируйте репозиторий

git clone https://github.com/RubXela/gigachat-sandbox.git

cd gigachat-sandbox/web-bot

## 2. Создайте виртуальное окружение
python -m venv .venv

source .venv/bin/activate  # Linux/Mac
## или

.venv\Scripts\activate     # Windows
## 3. Установите зависимости

pip install -r requirements.txt
## 4. Настройте ключ GigaChat

Скопируйте шаблон переменных окружения:

cp .env.example .env

Откройте созданный файл .env и вставьте ваш ключ авторизации.

## Содержимое .env:

GIGACHAT_AUTH_KEY=ваш_ключ_авторизации

## Как получить ключ:

Зайдите в developers.sber.ru.
Создайте проект → выберите GigaChat API.
Сгенерируйте Authorization key.
Скопируйте ключ в .env.

## 5. Запустите приложение

python app.py

## 6. Откройте в браузере

Перейдите по адресу:

http://127.0.0.1:5000

Важно: используйте Chrome или Edge для голосового ввода. Для стабильной работы открывайте через 127.0.0.1, а не localhost.

# 📖 Как пользоваться
## Текстовый ввод:
Напишите сообщение в поле ввода.
Нажмите Enter или кнопку ➤.
Бот ответит текстом и озвучит ответ (если включена озвучка).
## Голосовой ввод:
Нажмите и удерживайте кнопку 🎤.
Скажите свой запрос вслух.
Отпустите кнопку — текст распознается и отправится автоматически.

## Управление озвучкой

Нажмите 🔊 в правом верхнем углу, чтобы выключить озвучку. Повторное нажатие 🔇 включит её обратно.

## 🧪 Тестовые скрипты (папка python/)

Для быстрой проверки GigaChat без веб-интерфейса используются специальные скрипты.
python basic_request.py

## Отредактируйте .env — добавьте ваш ключ
cp ../.env.example .env


# 🔧 Устранение неполадок
## Микрофон не работает

Speech Recognition API требует HTTPS или локального хоста.

Локально: Используйте http://127.0.0.1:5000. Убедитесь, что браузер разрешил доступ к микрофону (замок 🔒 в адресной строке).
Публично (для демо): Используйте туннель с SSL.

npm install -g cloudpub
cloudpub 5000

Сервис выдаст публичный HTTPS-адрес вида: https://your-project.cloudpub.ru.

## Ошибка "GigaChat не доступен"
Проверьте ключ в .env (без лишних пробелов).
Проверьте интернет-соединение.

## Ошибка 404 для GigaChat

Проверьте URL в app.py (используется актуальный домен):

url = "https://gigachat.ru/api/v1/chat/completions"

## Папка .venv случайно закоммитилась?

Если папка попала в коммит:

git rm -r --cached .venv
echo ".venv/" >> .gitignore
git add .gitignore
git commit -m "Удалён .venv из репозитория"

# ⚠️ Конфиденциальность
