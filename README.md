# 🤖 Голосовой помощник на базе GigaChat

Веб-приложение с голосовым управлением, использующее **GigaChat API** для генерации ответов и встроенный **Web Speech API** для распознавания и синтеза речи.

> ⚡ Сделано в рамках подготовки к **Sber500xDisrupt** 🚀

---

## ✨ Возможности

- 💬 **Текстовый чат** с GigaChat.
- 🎙️ **Голосовой ввод** (нажми и удерживай кнопку микрофона).
- 🔊 **Озвучивание ответов** (можно включить/выключить).
- 📱 **Адаптивный дизайн** для мобильных устройств.
- 🟢 Индикатор печати бота.
- 🎯 Простой и понятный интерфейс для пожилых людей.

---

## 🛠️ Технологии

| Компонент | Технология |
| :--- | :--- |
| **Backend** | Python + Flask |
| **AI** | GigaChat API (Сбер) |

## 🚀 Быстрый старт (веб-бот)

### 1. Клонируйте репозиторий

bash

git clone https://github.com/RubXela/gigachat-sandbox.git
cd gigachat-sandbox/web-bot

### 2. Создайте виртуальное окружение
bash

python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# или
.venv\Scripts\activate     # Windows

### 3. Установите зависимости

bash

pip install -r requirements.txt

### 4. Настройте ключ GigaChat

Создайте файл .env в папке web-bot/:

bash

cp .env.example .env

# Отредактируйте .env — добавьте ваш ключ

Содержимое .env:
env

GIGACHAT_AUTH_KEY=ваш_ключ_авторизации

Как получить ключ:

  Зайдите в developers.sber.ru

  Создайте проект → выберите GigaChat API

  Сгенерируйте Authorization key

  Скопируйте ключ в .env

### 5. Запустите приложение
bash

python app.py

### 6. Откройте в браузере
text

http://127.0.0.1:5000

  Важно: используйте Chrome или Edge для голосового ввода.
  Для стабильной работы открывайте через 127.0.0.1, а не localhost.

# 📖 Как пользоваться
Текстовый ввод

  Напишите сообщение в поле ввода

  Нажмите Enter или кнопку ➤

  Бот ответит текстом и озвучит ответ (если включена озвучка)

Голосовой ввод

  Нажмите и удерживайте кнопку 🎤

  Скажите свой запрос вслух

  Отпустите кнопку — текст распознается и отправится автоматически

Управление озвучкой

  Нажмите 🔊 в правом верхнем углу, чтобы выключить озвучку

  Повторное нажатие 🔇 включит озвучку обратно

🔧 Устранение неполадок
Микрофон не работает

В браузерах Speech Recognition API (голосовой ввод) работает только по протоколу HTTPS или на localhost/127.0.0.1. Если вы тестируете через внешний IP-адрес или публичный URL — микрофон не будет работать.

Для локального тестирования:

  Используйте http://127.0.0.1:5000 или http://localhost:5000

  Убедитесь, что в браузере разрешён доступ к микрофону (нажмите на замок 🔒 в адресной строке → Микрофон → Разрешить)

Для публичного доступа (демо для менторов / пользователей):

  Установите SSL-сертификат для вашего сервера

  Используйте CloudPub для проксирования локального сервера в интернет с поддержкой HTTPS:


# Установите CloudPub
npm install -g cloudpub

# Запустите прокси для вашего приложения
cloudpub 5000

Сервис выдаст публичный HTTPS-адрес вида: https://your-project.cloudpub.ru, по которому микрофон будет работать корректно.

Коротко: для работы микрофона нужен HTTPS. Для локальных тестов достаточно 127.0.0.1. Для демо-доступа используйте CloudPub или любой другой туннель с поддержкой SSL.

Ошибка "GigaChat не доступен"

  Проверьте ключ в .env

  Убедитесь, что ключ скопирован без лишних пробелов

  Проверьте интернет-соединение

Ошибка 404 для GigaChat

Проверьте URL в app.py:
python

url = "https://gigachat.devices.sberbank.ru/api/v1/chat/completions"

.venv случайно закоммитился?

Если вы случайно добавили .venv/ в Git:
bash

git rm -r --cached .venv
echo ".venv/" >> .gitignore
git add .gitignore
git commit -m "Удалён .venv из репозитория"
